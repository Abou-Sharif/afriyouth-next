# AfriYouth Innovation Labs website

Public website for AfriYouth Innovation Labs, built with Next.js (App Router) and exported as a static site.

## Getting started

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build      # static export in ./out
pnpm lint
```

Requires Node 20 or newer.

## Structure

- `app/` routes and layouts
- `public/` images and logos
- `content/` page and program content (added as pages are built)
